# Vila das Meninas — Resumo de Identidade
> Fonte: Branding Guide v1.0 | Cliente de Advisory T2

---

## Identidade

| Atributo | Detalhe |
|----------|---------|
| **Nome** | Vila das Meninas |
| **Tagline** | "A Arte Encontra a Mesa" |
| **Segmento** | Centro Cultural Gastronômico |
| **Localização** | Pinheiros / Vila Madalena — São Paulo, SP |
| **Posicionamento** | De restaurante contemporâneo a centro cultural gastronômico |

---

## Essência da marca

- De Restaurante a Centro Cultural Gastronômico
- Onde a arte encontra a mesa
- Um refúgio intimista e acolhedor em Pinheiros

---

## Cores — "Arte, Terra e Alma"

| Token | Nome | Hex | Função |
|-------|------|-----|--------|
| `primary` | Terracota Artística | `#C2553A` | Cor dominante — logo, títulos, CTAs |
| `secondary` | Verde Jardim | `#4A6741` | Fundos secundários, ícones, menus |
| `surface` | Bege Caseiro | `#E8D5B7` | Áreas de respiro, backgrounds, cardápios |
| `accent` | Azul Ateliê | `#2E5A7E` | Detalhes culturais, links, eventos artísticos |

```css
:root {
  --color-primary:    #C2553A;  /* Terracota Artística */
  --color-secondary:  #4A6741;  /* Verde Jardim */
  --color-surface:    #E8D5B7;  /* Bege Caseiro */
  --color-accent:     #2E5A7E;  /* Azul Ateliê */
}
```

## Tom de voz

| Atributo | Descrição |
|----------|-----------|
| **Acolhedor** | Como quem recebe em casa — com carinho, sem formalidade excessiva |
| **Artístico** | Evoca sensações, cores e texturas — não descreve um prato, pinta uma experiência |
| **Descontraído** | Leve, sem ser superficial — como entre amigos ao redor da mesa |
| **Poético** | Valoriza a beleza das palavras — cardápio é livro, cozinha é tela, jardim é palco |
| **Autêntico** | Verdade e simplicidade mineira — sem jargões corporativos |

### Exemplos

| A marca DIRIA | A marca NÃO DIRIA |
|---------------|-------------------|
| "Hoje o jardim está especialmente bonito pra receber vocês. Vem?" | "Aproveite nossa promoção imperdível de 30% OFF!" |
| "Nosso risoto foi inspirado nas cores do pôr do sol que vimos ontem." | "Restaurante premium com gastronomia de alto padrão." |
| "Sexta à noite tem música ao vivo, vinho bom e conversa que alimenta a alma." | "Clique aqui e garanta sua reserva agora mesmo!" |

## Logotipo

**Símbolo:** A casinha estilizada (telhado com chaminé) — patrimônio visual da marca.

| Versão | Uso |
|--------|-----|
| **Vertical** (ícone + nome) | Versão principal — materiais institucionais |
| **Horizontal** (ícone + nome lado a lado) | Cabeçalhos, cardápios, assinaturas de e-mail |
| **Apenas ícone** | Avatares, favicons, selos em embalagens |
| **Monocromática / Negativa** | Sobre fundos escuros ou fotos |

**Cores do logo:** Ícone em Terracota Artística com detalhes em Verde Jardim. Nome em marrom escuro ou terracota.
