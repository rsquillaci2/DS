## Identidade

**Tipo:** Holding company
**Subtítulo oficial:** *Financial Holding* (uso formal) / *Holding Company* (uso institucional)

## Valores

| Valor | Descrição |
|-------|-----------|
| **Sólida Governança Corporativa** | Práticas de governança que assegurem transparência, eficiência e cumprimento das normas — gestão responsável e ética |
| **Inovação e Crescimento Sustentável** | Busca constante por novas oportunidades e soluções inovadoras, alinhadas às melhores práticas de mercado |
| **Responsabilidade** | Comprometimento com o desempenho dos negócios e com o impacto social — desenvolvimento das empresas e da sociedade |
| **Eficiência** | Otimização de resultados e aumento da rentabilidade dos ativos sob administração |

## Logotipo

**Conceito:** Inspirado em colunas gregas — simboliza força, durabilidade e suporte. A holding como "pilar" que sustenta o crescimento seguro dos negócios.

**Estilo:** Minimalista e elegante. Une tradição e inovação. Reforça autoridade e respeito.

## Tipografia

### Dejanire Headline — display / títulos

| Peso | Arquivo | Uso |
|------|---------|-----|
| Black | `Dejanire-Headline-Black.otf` | Impacto máximo, headlines grandes |
| Extra Bold | `Dejanire-Headline-Extra-Bold.otf` | Títulos de seção |
| Bold | `Dejanire-Headline-Bold.otf` | Títulos padrão |
| Medium | `Dejanire-Headline-Medium.otf` | Subtítulos |
| Regular | `Dejanire-Headline-Regular.otf` | Texto de destaque |
| Light | `Dejanire-Headline-Light.otf` | Textos grandes e arejados |
| Italic | `Dejanire-Headline-Italic.otf` | Ênfase, citações |
| Jewel | `Dejanire-Jewel.otf` | Uso especial / decorativo |

> Variações Dejanire Text disponíveis para textos corridos com maior legibilidade.

**Quando usar:** materiais institucionais, relatórios, apresentações, páginas de governança, materiais premium, sinalização física.

### Roboto — body / interface

| Peso | Arquivo | Uso |
|------|---------|-----|
| Black | `Roboto-Black.ttf` | Destaques secundários |
| Bold | `Roboto-Bold.ttf` | Labels, botões, ênfase |
| Medium | `Roboto-Medium.ttf` | Interface, navegação |
| Regular | `Roboto-Regular.ttf` | Corpo de texto padrão |
| Light | `Roboto-Light.ttf` | Textos longos, captions |
| Thin | `Roboto-Thin.ttf` | Uso decorativo, números grandes |
| *(+ variantes Italic de cada peso)* | | |

**Quando usar:** documentos, sites, redes sociais, newsletters, tabelas, botões, e-mails internos.

### Princípio de combinação
- **Dejanire Headline** → momentos estratégicos, impacto institucional
- **Roboto** → legibilidade, flexibilidade, elementos secundários
- As duas coexistem — nunca substituir uma pela outra
